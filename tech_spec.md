This should be a basic CRUD application that uses docker compose to run all required services locally.

/backend Backend is a fastapi application with strong typing throughout.  backend dependencies should be managed with poetry. 
/frontend Frontend is nextjs with application router and strong typing throughout.
/database Database is sqlite as a file.  

Developer should be able to spin up the app locally with docker compose up. 



* For the frontend, use material UI and only use typography to make style changes like color, font size, etc.
